# Bitcoin Price Prediction App

This is a Flask-based web application that predicts Bitcoin prices using XGBoost.

## Features
- Real-time Bitcoin Price fetching.
- Historical Data Analysis (EDA).
- Future Price Prediction for the next 30 days.
- Model Training (XGBoost).

## Deployment
Deployed on Hugging Face Spaces using Docker.
