ℹ️ About This App

This application demonstrates the power of Machine Learning in financial forecasting. It was originally a Streamlit prototype and has been re-engineered as a robust Flask web application.

🚀 Features

  • Data Fetching: Yahoo Finance (Historical) & CoinGecko (Live).
  • Machine Learning: XGBoost Regressor for time-series forecasting.
  • Visualization: Interactive charts powered by Plotly.js.
  • Architecture: Flask (Backend) + Bootstrap 5 (Frontend).
  • Advanced Coding: Developed with Advanced Agentic Coding.
